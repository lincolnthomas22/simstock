# Getting SimStock onto Steam

The code side is in `desktop/`. This directory is the other half: the things
Steamworks asks for that are not code, written down so they are not being
invented at the keyboard on the day.

- `checklist.md` — the account and app setup, in the order it has to happen,
  and what only a human with a bank account can do
- `store-page.md` — the store page copy, ready to paste
- `../desktop/steam-achievements.tsv` — the 39 achievements, generated from
  `game.js` by `tools/steam-achievements.js`, to work from when entering them
  in the Steamworks UI

Nothing here is legal advice. Where something looks like a judgement call —
the parody company names, the content survey answers — it is flagged as one
rather than answered.
